# DeepSeek V4 发布视频设计

## 元素定义

| 代号 | 实际内容 | 描述 |
|------|---------|------|
| LOGO | DeepSeek 鲸鱼 Logo | SVG 图标，主色调 #4ECDC4 |
| VER | "V4" 版本号 | 大号白色文字 |
| GLOW | 光晕背景 | 中心扩散的径向渐变 |
| CODE | 代码能力卡片 | 代码图标 + "代码生成" + 代码片段 |
| REASON | 推理能力卡片 | 推理链图标 + "深度推理" + 推理链 |
| MULTI | 多模态卡片 | 图像图标 + "多模态理解" + 识别框 |
| STATS1 | 95% 准确率 | 数字 + 进度条 |
| STATS2 | 3x 速度提升 | 数字 + 进度条 |
| STATS3 | 1M 日活 | 数字 + 进度条 |
| SLOGAN | "非常强大" | 主标语 |
| CTA | "立即体验" 按钮 | 渐变按钮 |

## 分幕设计

### 第一幕：Logo 入场
**时间范围**：0.0s - 5.0s
**元素清单**：LOGO, VER, GLOW

**最终布局**（居中垂直排列）：
```
┌────────────────────────────────┐
│                                │
│          [GLOW]                │
│                                │
│          [LOGO]                │
│          DeepSeek              │
│            [VER]               │
│              V4                │
│                                │
└────────────────────────────────┘
```

### 第二幕：能力展示
**时间范围**：5.0s - 10.0s
**元素清单**：LOGO（顶部小）, CODE, REASON, MULTI

**最终布局**（顶部 Logo + 三卡片横向）：
```
┌────────────────────────────────┐
│      [LOGO] DeepSeek V4        │
│                                │
│  ┌────────┐ ┌────────┐ ┌────────┐ │
│  │  [CODE] │ │[REASON]│ │ [MULTI] │ │
│  │ 代码生成 │ │深度推理│ │多模态理解│ │
│  └────────┘ └────────┘ └────────┘ │
│                                │
└────────────────────────────────┘
```

### 第三幕：数据展示
**时间范围**：10.0s - 15.0s
**元素清单**：STATS1, STATS2, STATS3

**最终布局**（三数据卡片横向）：
```
┌────────────────────────────────┐
│                                │
│  ┌────────┐ ┌────────┐ ┌────────┐ │
│  │  95%   │ │   3x   │ │   1M   │ │
│  │代码准确率│ │速度提升│ │ 日活用户 │ │
│  │███████ │ │███████ │ │███████ │ │
│  └────────┘ └────────┘ └────────┘ │
│                                │
└────────────────────────────────┘
```

### 第四幕：结尾号召
**时间范围**：15.0s - 20.0s
**元素清单**：SLOGAN, CTA

**最终布局**（居中）：
```
┌────────────────────────────────┐
│                                │
│                                │
│        "非常强大"              │
│        [SLOGAN]                │
│                                │
│      ┌──────────┐              │
│      │ 立即体验 │              │
│      │  [CTA]   │              │
│      └──────────┘              │
│                                │
│        DeepSeek                │
└────────────────────────────────┘
```
