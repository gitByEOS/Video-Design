# video-design

生成 HyperFrames 视频时间线设计文档，并渲染可视化甘特图，辅助视频制作。

## 四部曲

- 静态布局
- 时间线设计
- 动画实现
- 整合交付

## 使用方式
把 `skills/video-design` 拷贝到你的skills中，然后：
```
/video-design
```

## Demo

`my-video` 目录是就是用 `/video-design` 制作的，`design`目录下是本skill的过程产物

可以点击 `preview.html` 和 `time-line.html` 直接预览
